# UAT fixes — 14 October 2026

Historical implementation and deployment notes. The fixes have since been published and verified; see [Final regression report](regression-2026-10-14.md#final-uat-readiness-decision) for current status, including the subsequent mobile-input and GLS-email fixes.

## Changes

- Dashboard: removed the seven-day cutoff from pending consumer requests. The summary count now comes from the same pending list, so an old unresolved request cannot be counted but hidden. Recent-order filtering is unchanged.
- Router: all public, account and admin root routes now have an eagerly loaded Hungarian error screen. Its reload button performs a full document reload, clearing React's cached rejected lazy import. It never automatically reloads or loops and warns about unsaved edits. Raw module URLs/stack traces are not shown to customers.
- IIS frontend configuration: HTML responses request revalidation (`Cache-Control: no-cache`); missing `/assets/` files no longer get rewritten to HTML. Existing WebP MIME mapping is preserved.
- Product detail: zero available-to-add quantity displays “Jelenleg nincs szabad készlet” rather than claiming immediate availability. Physical-stock schema data and server purchase protection are unchanged.

The exact network cause of the intermittent live module-download failures was not established. Recovery is fixed and stale deployment/cache risks are reduced; this is not a claim that every possible hosting/network failure is eliminated.
